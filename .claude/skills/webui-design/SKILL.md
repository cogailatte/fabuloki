# Fabuloki dashboard

- Use the theme tokens in apps/web/src/app/globals.css. The Fabuloki palette uses a forest-green background, light green for primary actions and muted gold for small accents.
- Use the shared shell, cards, fields and buttons. Keep editing controls usable with the keyboard, and keep status, errors and labels visible at narrow widths.
- Use text-sm for content, text-meta for supporting context, and text-xs for compact status labels and table headers.
- Verify a real browser view at desktop and mobile widths when changing the shell, a key screen or the palette. The project check is documented in docs/SPEC.md.
