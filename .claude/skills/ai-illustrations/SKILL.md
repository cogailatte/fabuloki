# Project images

- Follow the project brief and Style Design. Generate images only when the relevant illustration option is enabled.
- Use the local Fabuloki illustration API for AI-generated assets. The API uses the Gemini connection configured in the dashboard.
- Keep the text on editable composition or timeline layers when possible. Reuse footage and user-provided images when no image connection is available.
- Reference the actual project-relative asset path returned by the API. Render and review the scene before reporting that it used the image.
